# The versions Poisson Tasks is tested with: every package a checkout's `pip install -e ".[dev]"`
# installs, at the version the whole suite last passed on (Python 3.11). Constraints, not
# requirements: a package the install does not ask for is not installed, and the package's own
# metadata keeps its floors and its two pins (verifiers and tiktoken), with no ceilings.
#
# CI's jobs without Prove install from it (`pip install -c constraints.txt ...`), so a new release
# of a dependency cannot turn a pull request red, and a run says exactly what it ran. The jobs with
# Prove install without it, so the newest releases (Prove's among them) are still met there first.
# To install a release's tested set yourself: `pip install poisson-tasks -c constraints.txt` with
# this file from that release's tag.
#

#   pip freeze --exclude-editable > freeze.txt
#   uv pip compile pyproject.toml --extra dev --universal --python-version 3.11 \
#     -c freeze.txt -o constraints.txt --no-header --no-annotate
